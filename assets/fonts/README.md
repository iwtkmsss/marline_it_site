# Локальні шрифти Marline

Завантажено 2026-11-16 з офіційного Google Fonts. Сайт використовує локальні WOFF2; звернення до Google CDN під час перегляду не потрібні.

- Golos Text: normal, variable weight 400–700, upstream v7.
- Unbounded: normal, variable weight 500–700, upstream v12.
- Для кожної родини збережено cyrillic-ext, cyrillic, latin-ext і latin. Unicode ranges перенесено без змін із CSS Google Fonts; українські Є/І/Ї/Ґ охоплені cyrillic.
- У fonts.css встановлено font-display: swap. Бінарні файли не модифіковані.

CSS-джерело (HTTP 200):

https://fonts.googleapis.com/css2?family=Golos+Text:wght@400..700&family=Unbounded:wght@500..700&display=swap
