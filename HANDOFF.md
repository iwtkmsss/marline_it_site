## Перевірки та обмеження

- Основна сторінка A: перевірено ширини 320/390/768/1440 px без горизонтального переповнення, мобільне меню/Escape/фокус при resize, акордеони, клавіатурні вкладки й прямі посилання на панелі, ручний режим меншого руху. Системну настройку ОС окремо не перемикали; перевірки screen reader не проводили.
- `npm run check` і `npm run build` пройшли. Збірка містить 18 публічних файлів (~1.86 MB), відповідає поточним вихідним файлам; її сторінка відкривається без console warning/error. PNG персонажа ще не оптимізований для остаточного production-бюджету.
- Використовувати `C:/Users/User/.codex/skills/modern-web-guidance/SKILL.md`: спочатку search/retrieve відповідних правил. Користувач обрав сучасні API + невеликі локальні fallback без сторонніх пакетів. Використані native details/popover, CSS scroll timelines, focusgroup з локальною клавіатурною підтримкою за відсутності API; непідтримуваний декоративний рух залишається статичним.
- Без JS описи етапів доступні як звичайний послідовний контент. Контакти — чесна заглушка, без форми надсилання. Коренева версія автоматично не синхронізується з Figma.
- Root перевірив A/B у браузері на desktop 1440 px та mobile 390/320 px, перемикання версій і відсутність горизонтального переповнення.
- Перевірено pixel assembly, перехід пікселів до процесу, anchors і ручний reduced-motion режим; системний режим ОС окремо не перемикали.
- Для JavaScript виконували `node --check design/motion-study/motion.js`; тестів для цього візуального прототипу не додавали.
- У Figma перевірено native Text, стилі/колірні змінні та демонстраційний Smart Animate; самі макети A/B статичні.
- Прямі Figma API tools у попередньому чаті були недоступні: працювали через браузерний UI після входу користувача.
- Наприкінці першої сесії денний Figma AI ліміт був вичерпаний. Це історичний стан — перевір актуальний; підписку не змінювали.
- Browser study є окремим дизайн-прототипом без framework/backend; зміни в ньому автоматично не оновлюють Figma.
