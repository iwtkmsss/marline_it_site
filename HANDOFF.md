# Marline — передача контексту

Оновлено: 2026-11-13. Перед роботою прочитай `AGENTS.md` і `PROJECT_CONTEXT.md`.

## Мета й підтверджений бриф

- Marline — сайт ІТ-компанії; перший макет українською.
- Пропозиція: розробка проєктів різної складності для різних бізнесів, занурення у бізнес-процеси, автоматизація й оптимізація.
- Головний персонаж зверху — піксельна Мерилін Монро; плавні, логічно пов'язані анімації та переходи особливо важливі.
- Зараз етап дизайну. Користувач ще **не обрав A або B**; production стек не визначений, production реалізація не починалася.
- Контактний сценарій, реальні кейси й контактні дані не визначені; не вигадувати їх.

## Перевірки та обмеження

- Root перевірив A/B у браузері на desktop 1440 px та mobile 390/320 px, перемикання версій і відсутність горизонтального переповнення.
- Перевірено pixel assembly, перехід пікселів до процесу, anchors і ручний reduced-motion режим; системний режим ОС окремо не перемикали.
- Для JavaScript виконували `node --check design/motion-study/motion.js`; тестів для цього візуального прототипу не додавали.
- У Figma перевірено native Text, стилі/колірні змінні та демонстраційний Smart Animate; самі макети A/B статичні.
- Прямі Figma API tools у попередньому чаті були недоступні: працювали через браузерний UI після входу користувача.
- Наприкінці першої сесії денний Figma AI ліміт був вичерпаний. Це історичний стан — перевір актуальний; підписку не змінювали.
- Browser study є окремим дизайн-прототипом без framework/backend; зміни в ньому автоматично не оновлюють Figma.
