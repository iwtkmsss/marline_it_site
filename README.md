# Marline

Робоча директорія для проєктування та подальшої реалізації українськомовного сайту ІТ-компанії Marline.

Поточний етап: **перегляд першої дизайн-концепції та вибір напряму**. Production реалізація ще не починалася.

Для макета обрано Figma: користувач хоче самостійно рухати й редагувати елементи, а також просити асистента вносити правки. [Файл дизайну](https://www.figma.com/design/xJeIYybQAQ2NyIu0Qhplnr?node-id=3-2) містить світлий напрям A, театральну альтернативу B, мобільний екран і сценарій руху. Локальна копія — [design/marline-concept-01.fig](design/marline-concept-01.fig), PNG-прев'ю — [design/previews/](design/previews/).

Окремий [motion study](design/motion-study/README.md) демонструє складання персонажа та піксельний зв'язок із процесом. Для локального перегляду запустіть із кореня репозиторію:

```powershell
python -m http.server 8473 --bind 127.0.0.1
```

Відкрийте [A — Світла](http://127.0.0.1:8473/design/motion-study/?version=a) або [B — Театральна](http://127.0.0.1:8473/design/motion-study/?version=b). У прототипі є перемикач версій. Залежності та збирання не потрібні; шрифти завантажуються з Google Fonts.

Підтверджені вимоги, пропозиції й відкриті питання зібрано в [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md). Детальне ТЗ першої концепції — [design/BRIEF.md](design/BRIEF.md).

Для нового агента: коротка передача контексту — [HANDOFF.md](HANDOFF.md). Перед роботою врахуйте актуальні інструкції в [AGENTS.md](AGENTS.md) і контекст проєкту.
