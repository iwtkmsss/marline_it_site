# Marline

Робоча директорія для проєктування та подальшої реалізації українськомовного сайту ІТ-компанії Marline.

Поточний етап: **розвиток основної frontend-версії A**. 2026-11-16 користувач обрав світлий напрям A та попросив продовжувати; контактний блок поки є заглушкою.

## Основна версія

Статична сторінка без runtime-залежностей: `index.html`, `src/site.css`, `src/site.js`, `src/motion.js`. Шрифти Unbounded і Golos Text зберігаються локально з OFL-ліцензіями в `assets/fonts/`.

Для розробки з кореня репозиторію:

```powershell
python -m http.server 8473 --bind 127.0.0.1
```

Основна сторінка: [http://127.0.0.1:8473/](http://127.0.0.1:8473/).

Перевірка та підготовка публічних файлів:

```powershell
npm run check
npm run build
npm run preview
```

Встановлення пакетів не потрібне. `build` збирає фіксований перелік публічних файлів у `dist/`; дизайн-джерела, документи, `.git` та файли середовища не копіюються. `preview` відкриває HTTP-сервер на [http://127.0.0.1:8474/](http://127.0.0.1:8474/). Для статичного хостингу призначений саме вміст `dist/`; домен і хостинг ще не обрані.
