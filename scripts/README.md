# Збірка Marline

`npm run build` запускає `build.mjs` на вбудованих Node.js API; встановлення залежностей не потрібне.

Збірка копіює лише фіксований список публічних файлів у `dist/`: основну HTML-сторінку, три файли `src`, favicon, PNG персонажа, локальні WOFF2, CSS шрифтів, їхні ліцензії та публічний README джерел. Дизайн-макети, промпти, інструкції, environment-файли й Git до збірки не потрапляють.

Перед очищенням `dist/` скрипт перевіряє абсолютний шлях: він має точно дорівнювати `<корінь проєкту>/dist`, а батьківською директорією має бути корінь проєкту. Symlink та junction у корені або всередині вихідної директорії відхиляються через `lstat`. Вхідні файли перевіряються й читаються до очищення попередньої збірки; відсутній, порожній або не звичайний файл завершує збірку явною помилкою.

Команди:

- `npm run dev` — локальний сервер з кореня на `127.0.0.1:8473`.
- `npm run check` — перевірка синтаксису двох browser JS і build-скрипту.
- `npm run build` — статична збірка у `dist/`.
- `npm run preview` — сервер лише збірки на `127.0.0.1:8474`.
